# Predictive Intelligence in R — CePH R Workshop Series 5

Universiti Malaya · Department of Social and Preventive Medicine · 11–12 November 2026 · Facilitator: Dr Vivek Jason Jayaraj

A two-day, hands-on `tidymodels` workshop: a leak-free pipeline; four model families — **random forests, support
vector machines, XGBoost, neural networks** (`nnet` and `brulee`/torch) — resampling and tuning (racing), clinically
meaningful evaluation and calibration, model explanation (DALEX, SHAP). **One self-guided tutorial per session**,
rendered to `docs/` for GitHub Pages. Successor to the 2023 SBDR series
(https://www.vivekjason.com/machine_learning_sbdr2023/).

## Quick start (instructor)

1. Open `ml_um2026.Rproj` in RStudio.
2. `source("setup/install_packages.R")` once.
3. `source("instructor/test_all.R")` — runs every tutorial's code and the take-home solution; reports failures (20–40 min).
4. `quarto render` — builds the site (agenda, tutorials with outputs, slides) into `docs/`.
   Then `source("instructor/make_participant_zip.R")` to build the zip for participants (includes `docs/`, excludes `instructor/` and `data-raw/`).
5. Push to GitHub; **Settings → Pages → Deploy from a branch → `main`, folder `/docs`**. Same mechanism as the 2023 site.
6. Read `instructor/facilitator_notes.md` and watch `instructor/statquest_watchlist.md`.

## Quick start (participant)

`setup.qmd` (or the rendered `docs/setup.html`): install R ≥ 4.3, RStudio, Quarto; run `setup/install_packages.R`;
run `setup/check_setup.R`; open `tutorials/01_pipeline.qmd` on the day.

## Layout

```
index.qmd / agenda.qmd / setup.qmd   site pages

slides/                 01 … 09 revealjs decks (+ theme.scss)
demos/                  SHORT live-coding teaching scripts, one per session (~15-20 min each) - the spine, not the whole tutorial

images/                 2023 illustrations (StatQuest-adapted) + images/gen/ (generated)
setup/                  install + check scripts, participant email
README_PARTICIPANTS.md  the start-here page that ships in the participant zip
instructor/             test_all.R · facilitator_notes.md · statquest_watchlist.md · purl_demos.R · takehome_hpt_solution.R · make_participant_zip.R
machine_learning_sbdr2023/   the 2023 project, for reference (excluded from rendering)
```

## Data

`data/nhms_synthetic.csv` is **fully synthetic** (5,000 rows, 41 columns), generated by
`data-raw/simulate_nhms_synthetic.py` with realistic risk gradients, MAR missingness, `-9` sentinel codes and
deliberately leaky biomarkers. See `data/data_dictionary.md`.
