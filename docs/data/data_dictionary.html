nhms_synthetic.csv — data dictionary

Fully synthetic. 5,000 simulated adults, generated by data-raw/simulate_nhms_synthetic.py (seed 20261111). The variable names and codings follow the NHMS-style extract used in the 2023 SBDR workshop so that the same narrative works, but no row is a real person and no value is derived from real survey records. Risk gradients were chosen to look plausible for Malaysian adults; they are not estimates of anything.

Why synthetic (and not the 2023 nhms_dummy.csv)? That file was built by scrambling each column independently, which removes every relationship between variables — cross-validated AUC for all three outcomes is 0.50. You cannot teach modelling on noise.

Clinical measurements — read this before modelling

Variable Meaning Sentinel
sys, dys Systolic / diastolic BP, mmHg -9 = not measured (4.6 %)
rbs Random blood sugar, mmol/L -9 = not measured (7.5 %)
rchol Random total cholesterol, mmol/L -9 = not measured (7.5 %)
  1. Recode -9 to NA first (dplyr::na_if()), or your imputation and scaling will be wrong.
  2. These are target-leaking variables. In NHMS an undiagnosed case is defined by this measurement: undx_dm is “no known diabetes and screening blood sugar above threshold”. rbs therefore sits on both sides of the equation. A model that uses rbs to predict undx_dm gets AUC ≈ 0.98 and is useless as a screening tool, because by the time you have rbs you already have the answer. Same for sys/dys → undx_hpt and rchol → undx_chol. The workshop’s “honest” predictor set is everything a community health volunteer could collect without a blood test or a BP cuff.

Expected performance (5-fold CV AUC, for your reference — participants should discover this)

Target Predictors Logistic Random forest XGBoost (tuned)
undx_dm with rbs (leaky) 0.98 0.98 0.99
undx_dm honest set 0.85 0.85 0.86
undx_hpt with sys/dys 0.99 0.98 0.99
undx_hpt honest set 0.82 0.82 0.83

The honest-set gaps between models are small by design — that is what tabular health data usually looks like. The simulated truth contains several interactions and thresholds (family history × obesity, sex-specific waist cut-offs, Indian ethnicity × overweight, post-menopausal catch-up in women, young-obese bump), which is where tree ensembles and neural networks earn their extra 0.01–0.02 AUC and what SHAP dependence plots should reveal.
